# Royal Sikh / Punjabi Wedding Invitation

An editorial luxury digital wedding invitation website crafted for **Hemant Singh & Jasleen Kaur**.

## ✨ Features

- **Editorial Vogue Aesthetics**: Warm Alabaster, Pure Ivory, Soft Gold Foil & Crisp Charcoal typography.
- **Interactive Invitation Folio Cover**: Magazine-style opening card with animated reveal & acoustic sound.
- **🌸 Interactive Blessing Petal Shower**: Physics-driven marigold, rose petal, and golden sparkle particle engine.
- **🎵 Multi-Track Web Audio Raga Synthesizer**: In-browser synthesized Indian classical tracks (*Raag Yaman Sitar*, *Sacred Kirtan*, *Festive Sangeet*).
- **📅 3-Day Itinerary Tabs**: Interactive schedule filter for Day 1, Day 2, and Day 3 events.
- **👗 Guest Dress Code & Color Swatches**: Interactive color palette guides for every ceremony.
- **☬ 4 Sacred Laavan Carousel**: Spiritual guide with Gurmukhi verses, English translations, and chime feedback.
- **🎟️ Personalized Digital Wedding Pass**: Real-time custom keepsake pass generator with print/save support.
- **❤️ Gallery with Lightbox & Heart Reactions**: Curated wedding photography with interactive reaction counters.
- **💌 RSVP & Live Wishing Well**: Response form with Sangeet DJ song requests and live guestbook stream.
- **🏛️ Amritsar & Delhi City Guide**: Hospitality recommendations for out-of-town guests.
- **📱 Fully Responsive**: Flawless experience across mobile phones, tablets, and desktop displays.

## 🚀 Quick Start / Local Preview

1. Clone this repository:
   ```bash
   git clone <repo-url>
   cd wedding
   ```
2. Start any local static server:
   ```bash
   python3 -m http.server 8080
   ```
3. Open `http://localhost:8080` in your browser.

## 🌐 Deploy to GitHub Pages

1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**. Your site will be live within 1–2 minutes!
